# Orbit

A collection of Python scripts for creating and animating celestial bodies and solar system scenes in Blender. The scripts use Blender's Python API to work with 3D objects, materials, lighting, and animation.

## Tech Stack

- Python
- Blender Python API (`bpy`)

## Setup

1. Install Blender from the [official Blender website](https://www.blender.org/download/).
2. Clone or download this repository.
3. Open Blender and switch to the **Scripting** workspace.
4. Open the Python script you want to run in Blender's text editor.
5. Update any local asset paths in the script so they point to files available on your computer.
6. Run the script inside Blender.

**Note:** The scripts use Blender-specific modules and are intended to run inside Blender, not as ordinary standalone Python scripts.
